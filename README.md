# Charlie's Igloo

A small browser demo: play as Chillin' Charlie, Happy Axie, Rex or JoJo (press G to switch), waddle around the igloo, then step outside onto Frosty Island.

**Play:** open the GitHub Pages link for this repo (Settings → Pages).

Controls: WASD to walk, Shift to run, Space to jump, click to capture the mouse and look around (Esc frees it), E / F to interact, 1–5 for emotes, G to change character, H to hide help.

Built from the Animation Suite (`npm run build:game`). Characters, art and sounds © StickiRolls.

On a phone: use the thumb stick to walk (push all the way to run), swipe to look, pinch to zoom, and the Jump / Emote / Friends buttons. Best played sideways.
