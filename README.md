# Charlie's Igloo

A small browser demo: play as Chillin' Charlie and waddle around his igloo, then step outside onto Frosty Island.

**Play:** open the GitHub Pages link for this repo (Settings → Pages).

Controls: WASD to walk, Shift to run, Space to jump, drag to look around, E / F to interact, 1–5 for emotes, H to hide help.

Built from the Animation Suite (`npm run build:game`). Characters, art and sounds © StickiRolls.
